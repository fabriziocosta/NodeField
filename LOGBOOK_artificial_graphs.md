# NodeField Artificial Graph Campaign Logbook

Artificial graph campaign runs append marked blocks here with the attempted proposal, sampled
exact configs, metrics, artifact links, and the next proposed range attempt.

Current logbook convention: each new run should have one conclusion paragraph, a compact metrics
table, one next-attempt paragraph, and a `Files to inspect` section with links to configs, logs,
metrics, snapshots, and loss PDFs. Narrative text should not include long artifact paths.
